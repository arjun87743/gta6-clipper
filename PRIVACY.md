# Privacy policy: clipper

clipper is a personal automation tool run by its owner for their own YouTube channel and Instagram account.

- It uses Google's YouTube Data API only to upload videos to the owner's own channel (scope `youtube.upload`).
- It does not read, collect, store or share data about any other person.
- Access tokens are kept as encrypted GitHub Actions secrets and are used only to publish the owner's videos.
- No data is sold or shared with third parties.
- Access can be revoked at any time at https://myaccount.google.com/permissions.
